# 📁 SistemaDeArchivos

Aplicación en **Java** orientada a la gestión y manipulación de archivos y directorios mediante operaciones del sistema de archivos.

## 🎯 Descripción

Este proyecto fue desarrollado como práctica académica para trabajar con operaciones relacionadas con el **sistema de archivos** utilizando Java.

La aplicación permite interactuar con archivos y directorios mediante diferentes operaciones, poniendo en práctica el manejo de rutas, archivos, carpetas y recursos del sistema.

## ⚙️ Funcionalidades

* 📁 Gestión de directorios.
* 📄 Gestión de archivos.
* 🔎 Consulta de información de archivos y directorios.
* ✏️ Manipulación de archivos.
* 🗂️ Navegación por el sistema de archivos.
* 💻 Ejecución de operaciones mediante Java.

## 🛠️ Tecnologías utilizadas

* **Java**
* **NetBeans IDE**

## 📚 Conceptos aplicados

* Manejo de archivos y directorios.
* Rutas del sistema de archivos.
* Operaciones de entrada y salida (I/O).
* Manejo de excepciones.
* Programación Orientada a Objetos.

## ▶️ Ejecución

1. Clonar o descargar este repositorio.
2. Abrir el proyecto en **NetBeans**.
3. Ejecutar la clase principal del proyecto.
4. Utilizar las opciones disponibles para realizar las operaciones sobre archivos y directorios.

## 🎓 Objetivo académico

El proyecto tiene como objetivo poner en práctica el manejo de archivos y directorios en Java, comprendiendo cómo una aplicación puede interactuar con el sistema de archivos del computador.
